Aktivasi Izin Firebase Realtime Database

Atur izin baca/tulis agar data anak dan berkas otomatis tersimpan di cloud

💡 Mengaktifkan Izin Realtime Database (Hanya 1 Menit):
Secara bawaan, Firebase Realtime Database memblokir akses jika Rules belum diizinkan. Cukup ubah .read dan .write menjadi true di Firebase Console.
Langkah-langkah:
  1. Klik tombol Buka Firebase Rules di bawah ini.
  2. Klik tab Rules (Aturan) di Firebase Console.
  3. Ubah aturannya menjadi seperti di bawah ini, lalu klik tombol Publish (Publikasikan).
